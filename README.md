# ハリセン工場パトロール

白菜とキャベツの食品工場で、**サボる人・悪口を言う人・じゃまする人**を見つけて、ハリセンで なんども たたいて改心させるブラウザのアクションゲームです。
みんな白い衛生服とマスクで **見えるのは目元だけ**。目つきと行動で善人・悪人を見分けます。

インストールは不要です。`index.html` は1ファイルで完結しているので、ブラウザで開くだけで遊べます(PC・スマホどちらも対応)。

## あそびかた

- 制限時間は 3分(難易度で変わる)。工場の中を歩きまわって、**目つきの わるい人**をさがす。
- **ハリセンで なんども たたく**と「ごめんなさい!」と改心して、まじめに はたらきはじめる(頭の上に ★)。でも しばらくすると **また サボりだす**。
- **まじめな人を たたくと -200**、こちらも げんきが へる。コンボも切れる。
- 改心させた人数が たまると、搬入口から **イジワルおばさん** が やってくる。倒せば ステージクリア。残り時間はボーナス。
- 連続で当てると **コンボ**(スコア最大 x3)。

### 見わけかた(目元)

| | 目元 | 行動 |
| --- | --- | --- |
| まじめな人 | まるい目・やさしい まゆ・ほっぺ | 作業台で白菜を切る、はこづめ。ときどき別の台へ歩く |
| サボり | 細い目・ねむそう・つり眉 | かべや段ボールに もたれて スマホ・あくび・Zzz。近づくと「しごと しごと♪」と はたらく ふりをする(ふつう以上) |
| 悪口コンビ | 細い目・ニヤリ・片まゆ上げ | すみっこで 2人 ヒソヒソ(点線の ふきだし)。近づくと だまる |
| じゃまする人 | つり眉・怒りマーク | はたらく人に ちょっかいを 出して「!」と こまらせる |
| イジワルおばさん(ボス) | 顔がとても大きい・まわりに暗いトーン・マスカラ・シワ | はたらく人の そばで ガミガミ いびる |

難易度「やさしい」では悪い人のまわりに うすい紫のトーンも出ます。「むずかしい」では目つきの差が小さく、ふりが上手で、再発も早くなります。

### ハリセン 3種

| 種類 | 効果 |
| --- | --- |
| ふつうのハリセン | いつでも使える。はやく振れる |
| ジャンボハリセン | ひろく つよく ふっとばす。1発2ダメージ。24回 |
| ビリビリハリセン | 当てた悪い人から 近くの悪い人へ 電気が はしり、しばらく めまい。30回 |

床に落ちているハリセン(キラキラ)の上を歩くと ひろえます。使い切ると ふつうのハリセンに もどります。

### イジワルおばさん

- まじめな人の そばに行って **いびる**(泣かせる)。いびっている あいだは よそ見しているので **ダメージ2倍**。
- 6連打で **めまい**(この間も2倍)。
- 近づくと **ガミガミ**: 赤いゾーンが出たら 外へ にげる。ステージ2からは **キャベツを投げる**、ステージ3では **手下を呼ぶ**。
- 倒すと「もう いじめません…」と改心して ステージクリア。

### ステージ・難易度

| ステージ | 場所 | ライン | 悪い人 | ボス |
| --- | --- | --- | --- | --- |
| 1 | 白菜ライン | 3本 | サボり3・悪口1組・じゃま1 | イジワルおばさん |
| 2 | キャベツライン | 4本 | サボり3・悪口2組・じゃま2 | ドイジワルおばさん(キャベツを投げる) |
| 3 | 出荷フロア | 4本 | サボり4・悪口2組・じゃま3 | 大イジワルおばさま(手下を呼ぶ) |

難易度(やさしい / ふつう / むずかしい)で、制限時間・ヒント・改心に必要な回数・再発までの時間・逆ギレ率・ボスのHPが変わります。ステージをクリアすると次のステージを選べるようになります(保存されます)。

## 遊ぶには

そのまま `index.html` をダブルクリック。うまく動かないブラウザでは、このフォルダでローカルサーバーを立てます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## つくり

画像・音声ファイルや外部ライブラリは使っていません。絵はすべて Canvas のパスで描き、効果音とBGMは WebAudio で合成しています。
`.claude/skills/web-game-forge/` のスキルの手順(企画 → 構成 → 実装 → ブラウザで検証)で作っています。

```
index.html        遊ぶためのファイル(src/ から自動生成した1ファイル版。直接は編集しない)
src/index.html    画面(タイトル・HUD・あそびかた・けっか)
src/style.css     HUD やカードのデザイン
src/js/util.js    共通の計算(乱数・扇形の当たり・経路探索など。DOM なし)
src/js/config.js  ゲームバランスの数値(ハリセン・作業員・ボス・難易度・ステージ)
src/js/world.js   工場のマップ生成(ライン・作業台・段ボール・サボり場所・歩けるセル)
src/js/art.js     作業員(目元の描き分け)・主人公・おばさん・ハリセン・野菜・ふきだしの絵
src/js/audio.js   効果音とBGM
src/js/input.js   キーボード・マウス・タッチ入力
src/js/entities.js プレイヤー・ハリセンの当たり・作業員AI・改心と再発・ボス・落ちているハリセン
src/js/render.js  描画(床 → ベルト → 奥から手前の物体 → 効果 → ふきだし)とミニマップ
src/js/main.js    起動・タイトル/プレイ/クリア/ゲームオーバーの切りかえ・メインループ・HUD
scripts/build.js  src/ を index.html にまとめる
tests/            ルール・マップ・ビルド・ブラウザ通しプレイのテスト
```

### 変更したら

`src/` を直したら `node scripts/build.js` で `index.html` を作り直します(古いままだとテストが失敗します)。

### 調整する

遊びごこちは `src/js/config.js` の数字で変えられます(ハリセン `harisen`、改心に必要なヒット数 `worker.hp`、難易度 `diff`、ステージ `stages`、ボス `boss` など)。

### テスト

```sh
node tests/logic.test.js                      # ルール・当たり・マップ
node tests/build.test.js                      # 1ファイル版が最新か
NODE_PATH=$(npm root -g) node tests/browser.test.js   # Chromium で起動し、ボットがステージ1をクリアするまで
```

URL のおわりに `?debug` をつけると、ブラウザのコンソールから `__harisen` でゲームの状態をのぞけます(動作確認用)。
